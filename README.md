LP Yacht Service

LP Yacht Service is a modern business website for a yacht and boat maintenance company based in Preveza, Greece.

The website presents the company, its marine services, previous projects, and contact options. It includes pages for services, project gallery, contact form, and privacy policy. The site supports both English and Greek, includes SEO metadata, and is prepared for deployment on Vercel.

Tech Stack

- React
- TypeScript
- Vite
- React Router
- Material UI
- CSS
- i18next / react-i18next
- EmailJS
- React Helmet Async
- Vercel Analytics
- Vercel Speed Insights
- Vercel
